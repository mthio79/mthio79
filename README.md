# Portfolio — Muhamad Thio Basudewo

Static bilingual (EN/ID) portfolio focused on Project Management and digital product delivery.

## Run locally
Open `index.html` in any browser, or serve the folder:

```powershell
python -m http.server 8000
```

Then visit http://localhost:8000.

## Structure
- `index.html` — single-page portfolio
- `css/styles.css` — theme + layout
- `js/main.js` — theme + language toggles
- `assets/resume.pdf` — downloadable resume
